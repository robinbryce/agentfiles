# forestrie/workflow/rules

Personal rule overlays for the forestrie scope — each a `<name>/SKILL.md`
directory, annotated with `user-invocable: false` and, where the rule is
file-type scoped, `paths:`. See
[workflow/rules/README.md](../../../../workflow/rules/README.md) for the
conventions.

The team rules in
[forestrie-agents](https://github.com/forestrie/forestrie-agents/tree/main/workflow/rules)
are folded in by [skills.sources](../../skills.sources) and applied *before*
this directory, so a rule here shadows the team one of the same name.

Prefer promoting a genuinely team-wide rule to forestrie-agents over keeping it
here — see [../../README.md](../../README.md).
